# 경력증명서

## 용도와 법적 성격

- 근로자가 특정 회사에서 일정 기간 근무한 사실(재직 기간, 직위, 담당 업무 등)을 그 회사가 확인해 주는 문서다. 다른 회사에 경력직으로 입사할 때 이전 근무 경력을 증명하거나, 자격·면허의 경력 요건 충족을 증빙하거나, 호봉 산정 등에 쓰인다.
- 법적 근거는 근로기준법 제39조(사용증명서)다. 사용자는 근로자가 청구하면 사용 기간, 업무 종류, 지위와 임금 등에 관한 증명서를 즉시 내주어야 하며, **근로자가 요구한 사항만 적어야 한다.** 시행령상 청구 가능 기간은 퇴직 후 3년 이내이고, 30일 이상 근무한 근로자가 대상이다(미발급·허위 기재 시 과태료 부과 대상).
- 유사 문서와의 구분: 재직증명서는 현재 재직 중인 사실을 증명하고, 경력증명서는 주로 퇴직한 과거 근무 사실을 증명한다. 4대보험 가입내역확인서로는 근무 기간을 증명할 수 있으나, 직위·담당 업무까지 증명하려면 경력증명서가 필요하다.

## 작성 전 확인사항

- **이 문서로 해결되지 않는 경우**: 프리랜서(위촉) 경력은 근로관계가 아니므로 경력증명서 대신 해촉증명서나 용역수행확인서가 적합하다. 폐업한 회사의 경력은 국민연금·건강보험 가입내역으로 갈음하는 경우가 많다.
- 퇴직 후 3년이 지난 청구는 회사가 거부할 수 있다(법정 의무 기간 경과). 발급 가능 여부를 먼저 확인한다.
- 제출처가 지정한 양식이나 필수 항목(담당 업무 상세, 주당 근로시간 등)이 있는지 확인한다.
- 발급일자 기준으로 유효기간을 따지는 제출처가 많다. 통상 작성일로부터 3~6개월 이내의 경력증명서를 요구하므로, 제출 시점에 맞춰 발급한다.

## 정보 수집 단계 (5단계)

### 1단계 — 발급 회사(사용자) 정보
- **질문**: 발급 회사의 상호, 대표자 성명, 회사 주소, 사업자등록번호를 알려주세요.
  - 회사명 예: 가나다 주식회사 / 대표자 예: 김대표 / 사업자등록번호 예: 123-45-67890
- **도움말**: 직인이나 대표자 서명이 없으면 이 증명서는 효력을 인정받기 어렵다. 내용을 모두 채워 저장한 다음 마지막에 직인을 찍거나 전자서명을 붙여 마무리한다.

### 2단계 — 근로자 정보
- **질문**: 경력을 증명할 근로자의 성명, 주민등록번호, 주소를 알려주세요.
  - 성명 예: 김근로 / 주소 예: 서울시 성동구 ○○아파트 101동 101호
- **도움말**: 개인정보를 최소화한다. 제출처가 요구하지 않으면 주민등록번호는 뒷자리를 마스킹하거나 생년월일로 대신하는 것을 권한다.

### 3단계 — 경력 사항(재직 기간·소속)
- **질문 1**: 재직 기간(입사일과 퇴사일)을 알려주세요.
  - **도움말**: 기준이 되는 것은 계약서에 적힌 기간이 아니라 근로자가 출근해 일한 실제 날짜다. 둘이 어긋날 때는 실제 근무한 기간으로 맞춰 적는다. 아직 다니는 중에 증명이 필요하면 종료일 자리에 "현재까지"라고 쓴다.
- **질문 2**: 소속 부서, 직책, 직위, 담당 업무를 알려주세요.
  - 예: 부서 = 개발팀 / 직책 = 팀장 / 직위 = 대리 / 담당 업무 = 프로그램 개발
  - **도움말**: 직책과 직위는 다른 개념이다. 직책은 맡은 역할에 따르는 책임(팀장, 본부장 같은 것)을 가리키고, 직위는 조직 내 등급(사원, 대리, 차장 같은 것)을 가리킨다. 담당 업무란을 비워 두면 받는 쪽에서 경력으로 쳐 주지 않는 일이 있으니, 요구 여부와 상관없이 채워 두는 편이 안전하다. 근무 도중 부서를 옮겼거나 승진한 이력까지 보여 줘야 한다면 기간을 끊어 단계별로 적는다.

### 4단계 — 발급 용도
- **질문**: 발급 용도를 선택해 주세요.
  1. 금융기관 제출용 (대출 신청, 신용카드 발급 등)
  2. 관공서 제출용 (여권, 비자 발급 등)
  3. 회사 제출용 (이직, 파견 근무 등)
  4. 직접 입력 (위에 해당하지 않는 경우, 용도를 직접 적는다)
- **도움말**: 길게 풀어 쓸 필요 없이 한 줄로, 예컨대 "용도: 금융기관 제출용" 정도면 된다. 어디에 쓸지 분명히 박아 두면 다른 데로 돌려 쓰는 일을 막는 효과도 있다.

### 5단계 — 발급일자와 발급번호
- **질문 1**: 발급일자를 알려주세요. (예: 2025.01.01.)
- **질문 2**: 문서 발급번호가 필요하면 입력해 주세요. (예: 2025-001 → "제 2025-001 호")
  - **도움말**: 문서를 번호로 관리하는 경우 발급번호를 적어 두면 추후 관리가 쉽다. 필수 항목은 아니다.

## 필수 기재사항 체크리스트

- [ ] 근로자 성명·주민등록번호(또는 생년월일) — 동일인 확인
- [ ] 근로자 주소
- [ ] 재직 기간(입사일~퇴사일) — 경력 산정의 핵심
- [ ] 소속 부서·직책·직위·담당 업무 — 경력 인정 심사 항목
- [ ] 발급 용도 — 오·남용 방지
- [ ] 발급일자 — 제출처 유효기간 판단
- [ ] 발급 회사 정보(상호·사업자등록번호·대표자·주소)와 직인 — 누락 시 효력 불인정
- [ ] (요구 시에만) 퇴직 사유·임금 — 임의 기재 금지

## 작성 후 안내

- 회사 직인을 날인한 뒤 원본을 교부한다. 제출처가 여럿이면 용도별로 따로 발급한다.
- 사용자(회사) 유의: 30일 이상 근무한 퇴직자가 퇴직 후 3년 내에 청구하면 즉시 발급할 의무가 있고, 근로자가 요구하지 않은 불리한 사항(징계·해고 사유 등)을 적어서는 안 된다. 취업을 방해할 목적으로 비밀 기호나 명부를 작성·통신하는 행위는 근로기준법 제40조 위반으로 형사처벌 대상이다.
- 근로자 유의: 퇴사 시점에 미리 발급받아 두는 것이 가장 확실하다(회사 폐업·연락 두절 대비).
- 경력증명서는 제출처에 따라 유효기간이 다르며, 작성일로부터 3~6개월 이내 발급분을 요구하는 경우가 많으므로 제출 시점을 고려해 발급일자를 정한다.
