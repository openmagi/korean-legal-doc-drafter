# 내용증명(부동산 계약해지-세입자용)

> 카테고리: 내용증명 | 난이도: 중 | 예상 질문 라운드: 5회

## 용도와 법적 성격

- 세입자(임차인)가 임대인에게 임대차계약의 해지 또는 갱신 거절(더 살지 않겠다는 뜻)을 통지하고, 필요 시 보증금 반환을 함께 요구하는 문서다. 해지·갱신거절은 도달해야 효력이 생기는 의사표시이므로(민법 제111조), "언제 통지했는가"가 보증금 반환 시점과 직결된다. 내용증명으로 도달 시점을 증거화하는 것이 핵심이다.
- 근거 법령: 주택임대차보호법(이하 주임법) 제6조(묵시적 갱신), 제6조의2(묵시적 갱신 시 임차인의 해지 — 통지 후 **3개월** 경과 시 효력), 제6조의3(계약갱신요구권), 민법 제623조·제627조(임대인의 수선의무 위반·사용수익 불능 시 해지). 상가 임차인이면 상가건물 임대차보호법(이하 상임법) 제10조 제5항(묵시갱신 중 임차인 해지 — 3개월) 적용.
- 유사 문서와의 구분: 이미 계약이 끝났는데 보증금만 못 받고 있는 상황이면 보증금 반환 청구 내용증명이 본체다. 이 문서는 "계약을 끝내는 통지"가 중심이고, 보증금 반환 요구는 부수 단락으로 들어간다. 집의 하자 수리만 원하면 하자보수청구 문서를 쓴다.

## 작성 전 확인사항

- 해결되지 않는 경우:
  - **계약기간 중도해지**는 임차인에게 법정 해지권(하자로 인한 사용 불능, 묵시적 갱신 중 등)이 없는 한 일방적으로 할 수 없다. 중도 퇴거 시 잔여기간 차임 부담 문제가 생기므로, 어느 분기에 해당하는지 먼저 확인한다.
  - 갱신 거절 통지 시기를 놓친 경우: 임차인도 기간 만료 **2개월 전까지**(주임법 제6조 제1항) 통지하지 않으면 묵시적 갱신이 된다. 다만 묵시적 갱신 후에도 임차인은 언제든 해지 통지가 가능하다(3개월 후 효력).
- 준비물: 임대차계약서 사본, (하자 해지 시) 하자 사진·수리 요구 내역, 보증금 입금 내역, 임대인의 현재 주소.

## 정보 수집 단계 (5단계)

### 1단계 — 당사자 유형
- **질문 1**: 발신인(세입자)은 어느 유형입니까?
  1. 법인
  2. 개인사업자
  3. 개인
- **질문 2**: 수신인(집주인)은 어느 유형입니까?
  1. 법인
  2. 개인사업자
  3. 개인
  - 도움말: 등기하여 설립한 회사면 법인, 등기 없이 사업자등록만 한 경우는 개인사업자, 둘 다 아니면 개인을 고른다. 유형에 따라 호칭("귀하" 또는 "귀사")과 상세정보 입력란(법인명·대표이사 / 상호·사업주명 / 성명)이 달라진다.
- **질문 3**: 각 당사자의 이름(법인명·상호·성명)은 무엇입니까?

### 2단계 — 임대차계약 내용
- **질문 1**: 계약을 체결한 날짜는 언제입니까? (예: 2024.12.31.)
- **질문 2**: 임차 목적물 주소는 어디입니까? (예: 서울 강남구 테헤란로 1004 잘사는빌리지 3층)
- **질문 3**: 임차기간은 언제부터 언제까지입니까? (시작일·종료일)
- **질문 4**: 임대차 형태는 무엇입니까?
  1. 월세 및 반전세
  2. 전세
- **질문 5**: 임대차보증금은 얼마입니까? (예: 100,000,000원)
  - (월세·반전세인 경우) 월 임대료와 지급일(매달 며칠)을 함께 입력한다.
  - 도움말: 임대차계약서의 기재 내용을 그대로 옮겨 적는다.
- **분기**: 월세형이면 본문에 "임대료 월 ○원을 매달 ○일 지급" 문구가 삽입되고, 전세형이면 보증금만 표시된다.

### 3단계 — 해지 사유와 계약 현황
- **질문**: 지금 상황은 어디에 해당합니까?
  1. 계약이 이미 종료됨
  2. 기간 만료 시 종료 예정(갱신하지 않음)
  3. 묵시적으로 갱신된 상태이며 종료하려 함
  4. 집의 하자로 더 이상 거주가 불가능함
- **분기별 추가 질문**:
  - 4번(하자)을 고르면 → 하자 내용(예: 노후 수도관 하자로 수리 및 거주 불가)과 현재 계약 상태(현재 임대차 기간 중 / 묵시적 연장 상태로 기간 중)를 추가로 입력한다.
  - 2·3·4번을 고르면 → 이미 해지를 통지했는지 묻는다(이미 통지함 / 본 내용증명으로 통지함). 이미 통지했다면 통지일(예: 2024.12.31.)을 입력한다.
  - 1번(이미 종료됨)을 고르면 → 종료 사유를 묻는다.
- **종료 사유(1번 선택 시)**:
  1. 기간만료로 종료
  2. 합의로 종료 → 합의한 날짜 입력
  3. 임차인 잘못으로 해지 → 연체/손해배상 항목으로 진행
  4. 임대인 사유로 해지 → 사유 직접 입력(예: 임대인이 실거주하려 함)
- **임차인 잘못으로 해지한 경우(3번)**:
  - 임대료 연체가 있으면 연체 기간 유형(과거부터 현재까지 / 과거 특정기간 / 미지급 특정 시점)과 연체 금액을 입력한다.
  - 원상복구 등 손해배상 사유가 있으면 손해배상 금액을 입력한다.
- **주의**: 갱신거절(2번)에서 통지 기한(만료 2개월 전)을 넘기면 묵시적 갱신이 되어 3번 구조(도달 후 3개월 대기)로 바뀐다. 날짜 계산을 반드시 확인한다. 계약갱신요구권을 쓴 갱신 기간 중이라도 임차인은 주임법 제6조의2를 준용해 중도 해지 통지가 가능하다(제6조의3 제4항).

### 4단계 — 보증금 반환 청구
- **질문 1**: 보증금의 일부를 이미 돌려받았습니까? (일부 받음 → 받은 금액 입력 / 받은 금액 없음)
- **질문 2**: 임대인이 보증금을 언제까지 반환해야 합니까? (지급 기한, 예: 2024.12.31.)
- **질문 3**: 기한 내 미반환 시 법적 조치를 예고하시겠습니까? (진행함 / 진행하지 않음)
- **질문 4**: 반환받을 계좌 정보를 적으시겠습니까? (입력함 → 예금주·은행명·계좌번호 / 입력하지 않음)
- **주의**: 보증금 반환과 목적물 인도(이사·열쇠 반환)는 **동시이행 관계**다. 효력발생일 전의 지연손해금은 청구할 수 없다.

### 5단계 — 특별손해 고지 및 당사자 상세정보
- **질문 1**: 보증금을 제때 못 받으면 발생할 구체적 손해(예: 새집 잔금 미지급으로 인한 계약금 몰취, 대출이자)가 있습니까? (있음 → 내용 입력 / 없음)
  - 도움말: 민법 제393조 제2항상 임대인이 그 사정을 알았거나 알 수 있었어야 배상 대상이 되므로, 이 내용증명으로 미리 알려두는 것이 실익이다.
- **질문 2**: 각 당사자의 상세정보(주소, 전화번호, 법인이면 대표이사, 개인사업자면 사업주명)를 입력한다.
- **주의**: 임대인이 계약 후 바뀌었다면(매매 등) 양수인이 임대인 지위를 승계하므로(주임법 제3조 제4항) 현재 소유자를 수신인으로 한다. 등기부등본으로 확인한다.

## 필수 기재사항 체크리스트

- [ ] 임대차계약의 특정(체결일·목적물 주소·보증금/차임) — 누락 시 어떤 계약의 해지인지 불명
- [ ] 해지·갱신거절의 명시적 의사표시 — 누락 시 단순 문의로 해석될 위험
- [ ] 해지 효력 발생일(만료일 / 도달 후 3개월 / 즉시) — 누락 시 차임 정산·보증금 반환 기준일 분쟁
- [ ] (하자 해지 시) 하자 내용과 수리 요구 경과 — 누락 시 해지 사유 입증 곤란
- [ ] 보증금 반환 액수·기한·계좌 — 누락 시 별도 청구 필요
- [ ] 퇴거(명도) 예정일 — 누락 시 동시이행 관계 정리 곤란

## 작성 후 안내

- 3부 출력하여 우체국 내용증명 + 배달증명으로 발송한다. 갱신거절 통지는 **만료 2개월 전 도달**이 데드라인이므로 여유를 두고 보낸다.
- 임대차 종료 후 보증금을 못 받은 채 이사해야 한다면, 이사 전에 **임차권등기명령**(주임법 제3조의3)을 신청하고 등기가 완료된 후에 전출해야 대항력·우선변제권이 유지된다. 이 순서를 어기면 보증금 보호가 깨진다.
- 종료일 이후에도 미반환 시 보증금 반환 청구 내용증명을 거쳐 지급명령 신청(보증금 반환 청구) 순으로 진행한다.
- 보증금 규모가 크거나 임대인의 자력이 의심되면 변호사·법률구조공단 상담을 권한다.
