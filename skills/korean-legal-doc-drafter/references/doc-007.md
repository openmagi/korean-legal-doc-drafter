# 주식인수증 (일반)

## 용도와 법적 성격

- 회사 설립 또는 신주 발행 과정에서 인수인이 **특정 주식을 인수하였음을 확인**하기 위해 작성하는 서면이다. 설립등기나 변경등기 신청 시 첨부서면으로 쓰이거나, 회사와 인수인 사이에 인수 사실을 입증하는 증거자료로 활용된다.
- 발기설립의 경우 발기인의 주식 인수는 서면으로 하여야 하며(상법 제293조), 모집설립에서는 모집주주가 주식청약서 2통으로 청약한다(상법 제302조). 본 문서는 이렇게 이루어진 인수 사실을 사후에 확인·증명하는 데 쓰인다.
- 유상증자 등기를 할 때에는 주식을 인수한 주주로부터 주식청약서와 함께 주식인수증을 날인 받아 반드시 첨부해 제출해야 한다.
- 구별이 필요한 인접 문서가 있다. 청약 단계의 법정 서면인 주식청약서와는 별개이고, 이미 발행된 주식을 매매하는 주식양수도계약서와도 다르다. 회사가 새로 발행하는 주식을 받는 거래가 곧 주식 "인수"다.

## 작성 전 확인사항

- **이 문서로 해결되지 않는 경우**: 기존 주주에게서 주식을 사들이는 거래라면 주식양수도계약서를 작성한다. 우선주·청산우선권 등 투자 조건이 결부된다면 신주인수계약서나 투자계약서가 별도로 필요하다.
- 준비물: 회사의 1주 금액과 발행 조건(이사회 또는 주주총회 결의 내용), 인수인의 신분증 또는 법인 등기사항전부증명서.
- 인수가액 납입은 인수증과는 별개의 절차다(주금납입 보관 계좌를 통해 이루어진다). 인수증만으로는 납입 사실이 증명되지 않는다.
- 액면미달 발행은 원칙적으로 금지되므로(상법 제330조), 발행가액이 액면가보다 낮게 입력되는 경우에는 한 번 더 확인한다.

## 정보 수집 단계 (3단계)

### 1단계 — 회사와 인수인
1. 주식을 발행하는 **회사명(상호)**을 적어 주세요. (설립 중이라면 "설립 중의 회사 ○○ 주식회사"로 특정합니다.)
2. **주식을 넘겨받을 사람(주식인수인)의 성명**을 적어 주세요.

### 2단계 — 인수할 주식과 납입 은행
1. 인수할 **주식의 종류**를 선택하세요.
   - ① 보통주
   - ② 우선주
2. 인수할 **주식의 수량**을 적어 주세요. (단위: 주)
3. **1주당 금액**을 적어 주세요. (단위: 원) — 인수가액 총액은 수량 × 1주당 금액으로 자동 산정됩니다.
4. 주식 거래 대금을 납부할 **은행(주금납입기관)**을 적어 주세요. (예: ○○은행 ○○점)
   - 도움말: 납입 장소를 적어 두면 등기와 분쟁 양쪽에서 인수→납입 흐름을 입증하기 좋습니다.

### 3단계 — 주식인수인 상세정보
1. 주식인수인의 **성명**을 다시 확인해 주세요. (1단계 입력값과 동일해야 합니다.)
2. 주식인수인의 **주소**를 적어 주세요. (기본 주소와 상세 주소를 나누어 입력합니다.)

## 필수 기재사항 체크리스트

- [ ] 상호(회사명) — 누락 시 어느 회사의 주식인지 특정 불가
- [ ] 인수할 주식의 종류 — 보통주/우선주 구분 누락 시 인수 범위 분쟁
- [ ] 인수할 주식의 수 — 누락 시 인수 범위 불명확
- [ ] 1주의 금액과 인수가액 총액(금액 병기) — 누락 시 납입 의무 범위 불명확
- [ ] 주금납입기관(은행) — 납입 장소 미기재 시 납입 흐름 입증 곤란
- [ ] 주식인수인의 성명·주소와 기명날인 — 누락 시 증명 기능 상실
- [ ] 작성 일자 — 누락 시 등기 첨부서면으로 부적합

## 출력 템플릿

```
주 식 인 수 증

┌─────────────────────┬─────────────────────┐
│         상   호       │      [회사명]         │
├─────────────────────┼─────────────────────┤
│   인수할 주식의 종류    │   [주식 종류]         │
├─────────────────────┼─────────────────────┤
│    인수할 주식의 수     │   [주식 수량]주        │
├─────────────────────┼─────────────────────┤
│       1주의 금액       │   [1주당 금액]원       │
├─────────────────────┼─────────────────────┤
│        인수가액        │   [인수가액 총액]원     │
├─────────────────────┼─────────────────────┤
│      주금납입기관       │   [납입 은행]         │
└─────────────────────┴─────────────────────┘

아래 서명한 [인수인 성명](이하 '주식인수인')은 위 표에 기재된
주식을 [회사명](이하 '귀사')으로부터 인수하였음을 확인합니다.


[인수인 성명] (서명 또는 인)
주소: [인수인 주소] [상세 주소]


                        [작성 연월일]

                          [회사명]
```

- 인수가액 총액 = 인수할 주식의 수 × 1주의 금액으로 계산해 적는다.
- 금액은 아라비아 숫자와 함께 한글 표기를 병기하는 것이 안전하다. (예: 금 50,000,000원 (오천만 원))

(설립 시 발행 주식인 경우)
표 아래에 "위 주식은 설립 중의 회사 [회사명]이(가) 설립 시에 발행하는 주식임을 확인합니다."라는 문구를 덧붙여 인수 대상을 특정한다.

(신주 발행인 경우)
표 아래에 "위 주식은 [결의 연월일] 자 [이사회/주주총회] 결의에 따라 발행하는 신주임을 확인합니다."라는 문구를 덧붙여 인수 대상을 특정한다.

(인수인이 법인인 경우)
서명란을 "법인명 / 대표이사 성명 / 법인인감"으로 바꾸고, 주소는 본점 소재지를 적는다.

## 작성 후 안내

- 인수인이 날인(개인은 서명 또는 인감, 법인은 법인인감)하여 회사에 제출하고, 인수인 본인도 사본 1부를 보관한다.
- 설립등기나 변경등기에 첨부할 경우, 등기소나 법무사가 요구하는 형식(인감 날인 여부 등)을 미리 확인한다.
- 인수가액 납입 후에는 주금납입보관증명서(소규모 회사 설립 시에는 잔고증명)와 함께 보관하면 인수에서 납입으로 이어지는 흐름을 입증할 수 있다.
- 투자 조건이 결부된 인수라면 본 인수증 외에 신주인수계약서를 별도로 체결하고 전문가 검토를 받는 것이 안전하다.
